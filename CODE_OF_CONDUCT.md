# Code of conduct

PR Time Machine is a learning-friendly project. Beginners are welcome here.

- Be respectful and assume good intent. Critique code, not people.
- Explain, don't gatekeep. If someone asks a basic question, answer it or point to a resource.
- No harassment, discrimination, or personal attacks in issues, pull requests, or discussions.
- Keep feedback specific and actionable.

Maintainers may edit or remove contributions and block participants who break these rules. To report a problem privately, open a GitHub security advisory or contact the maintainers listed in the repository profile.

This document is inspired by the Contributor Covenant (https://www.contributor-covenant.org).
